# Jaswin — GTA-inspired 3D Portfolio

## Run
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr as an ES module, and Google Fonts are loaded online. No build step is required.

## What's included
- Procedurally modeled Three.js sports car with wheels, lights, bodywork, and spoiler
- Hand-built neon street scene with procedural buildings, window lights, fog, and road markings
- Cinematic camera motion and pointer-influenced camera framing
- Low-poly stylized character beside the car
- Click-to-enter title screen and responsive portfolio sections
- Projects, skills, education, internship, and contact links based on the provided resume

## Notes
The 3D car, city, and character are original procedural shapes (not GTA game assets). The experience is GTA-inspired, not affiliated with Rockstar Games. The scene requires WebGL and an internet connection to load Three.js.
